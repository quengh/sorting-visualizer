# Sorting Algorithm Visualizer

[![English](https://img.shields.io/badge/Language-English-blue)](README.md)
[![中文](https://img.shields.io/badge/语言-中文-red)](README.zh-CN.md)

Interactive sorting algorithm visualizer with bilingual support (English/Chinese). Supports 6 popular sorting algorithms including Bubble Sort, Selection Sort, Insertion Sort, Quick Sort, Merge Sort, and Heap Sort.

## 🇺🇸 English

### Features
- 6 Sorting Algorithms
- Interactive Controls
- Visual Features
- Bilingual Support

### Quick Start
1. **Prerequisites**: Node.js 18+
2. **Installation**: `npm install`
3. **Run**: `npm run dev`
4. **Open**: `http://localhost:5173`

### How to Use
1. Select algorithm from dropdown
2. Adjust array size (10-100)
3. Set animation speed
4. Click "Generate Array"
5. Click "Start Sorting"

### Deployment
**Vercel (Recommended)**
1. Push to GitHub
2. Import project in Vercel
3. Click "Deploy"
