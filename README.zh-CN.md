# 排序算法可视化器

[![English](https://img.shields.io/badge/Language-English-blue)](README.md)
[![中文](https://img.shields.io/badge/语言-中文-red)](README.zh-CN.md)

交互式排序算法可视化器，支持中英文双语。支持 6 种常用排序算法，包括冒泡排序、选择排序、插入排序、快速排序、归并排序和堆排序。

## 🇨🇳 中文

### 功能特性
- 6 种排序算法
- 交互式控制
- 视觉特性
- 双语支持

### 快速开始
1. **环境要求**: Node.js 18+
2. **安装**: `npm install`
3. **运行**: `npm run dev`
4. **打开**: `http://localhost:5173`

### 使用方法
1. 从下拉菜单选择算法
2. 调整数组大小（10-100）
3. 设置动画速度
4. 点击"生成数组"
5. 点击"开始排序"

### 部署
**Vercel（推荐）**
1. 推送到 GitHub
2. 在 Vercel 中导入项目
3. 点击"Deploy"
